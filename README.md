Адаптивный сайт с переключением тёмной и светлой темы.

Технологии
- HTML, CSS, JavaScript
- Mobile first
- CSS-переменные для тем
- Flexbox и Grid

Структура
- Шапка с меню переключения тем
- 4 секции с информацией о концентрации внимания
- Галерея изображений
- Футер

Особенности
- Поддержка тёмной и светлой темы
- Адаптив под мобильные, планшеты и десктопы
- Декоративные уголки через псевдоэлементы
- Переключение тем принудительное и по системным настройкам
